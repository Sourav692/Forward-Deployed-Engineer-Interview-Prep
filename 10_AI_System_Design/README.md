Open each HTML file directly: fonts, diagrams, request walkthrough and lab are embedded. Python labs require Python 3.10+ and the standard library; simulator checks additionally require Node. Each guide documents its exact commands. Model training, provider calls, cloud networking, and production deployment are not performed by the new exercises.

Complete stage ZIPs and SHA-256 checksums are in `dist/`. Each archive preserves workspace-relative paths and includes the stage, prerequisite guides/labs reached by local links, applicable ADRs, current architecture and coverage at that stage, and authoring validation tools. Caches, databases, credentials, and render captures are excluded.
