# Learn UX: Breadcrumbs, Copy Deck and Wireframes

Date: 5 October 2026. Phase 1 tasks UX-03, UX-04 and UX-06 of `2026-10-05-production-implementation-plan.md`, built in FE-06 to FE-09. The copy below is the source of truth for wording; the code copy lives in `site/src/components/learn/copy.ts` and must stay in step with this file.

## Breadcrumb rules (UX-03)

The trail follows the curriculum: **Learn › Track › Section › Module › Lesson**. The component is `Breadcrumbs` in `site/src/components/learn/Breadcrumbs.tsx`.

| Page | Trail | Current page (no link) |
|---|---|---|
| `/learn` | none (area level) | — |
| Track | Learn › T5 AI Systems Design | Track |
| Module | Learn › T5 AI Systems Design › Casebook › T5.5 Scenario library | Module |
| Lesson | Learn › T2 … › Retrieval › T2.4 Retrieval: hybrid, rerank … › Lesson title | Lesson |

- Labels: tracks and modules show code then title ("T2.4 Retrieval: hybrid, rerank, query transformation"); sections show their title only; lessons show the lesson title.
- Links: every crumb but the last is a link. The section crumb links to the track page with the section anchor (`/learn/<track>#<section>`), because sections have no page of their own.
- Semantics: `nav[aria-label="Breadcrumb"] > ol`; the last crumb carries `aria-current="page"`; separators are decorative SVG chevrons (`aria-hidden`).
- Truncation at 375 px (below the `sm` breakpoint, 640 px):
  - Learn and the immediate parent always show. Every crumb between them collapses into a single "…".
  - Ancestor labels are capped at 10rem (14rem from 640 px) and end in an ellipsis.
  - The current page takes the remaining width and truncates last.
  - The trail never wraps and never causes horizontal scroll.

## Copy deck (UX-06)

British English. Titles in title case with the serial comma. Buttons start with a verb. Errors say what happened and what to do.

### Gap states

| State | Where | Copy |
|---|---|---|
| Partly ready | After the published lessons on the module page | **Partly ready.** The lessons below are published. The rest of this module is still being written. Coming soon in this module: {gapNote} |
| Coming soon | Under the module header; no lesson list | **Coming soon.** This module has no lessons yet. The objective and scope below say what it will cover, and the related modules teach part of it today. |
| Coming soon, no related module | End of page | No other module covers this topic yet. Check back after the next content update. |
| On hold | Under the module header; no lesson list | **Paused, will return.** This module is paused while its material is reworked. It will return; until then, the related modules below cover the nearest ground. |

Rules: on-hold pages never show `holdNote` or any repository path. Coming-soon pages do not show `gapNote` (it is written for the owner, for example "Nothing in the repository teaches SQL"); partly-ready pages do, because it names what is coming.

### Reading list

| Case | Copy |
|---|---|
| Heading | Lessons |
| Module owns no lessons (T1.4, T1.5): see-also list becomes the main list | This module has no lessons of its own. Everything it teaches lives in other modules, so read these in order. |
| See-also list under the main list | **Also used in this module.** Lessons taught in another module that this one builds on. |
| Live lesson (opens an existing `/modules/...` page) | "Opens the practice page" under the title, plus a **Mark read** toggle on the row |
| Credited lesson | "Credited source" under the title |
| Empty list | No lessons are published for this module yet. |

### Prerequisites (soft gating)

| Case | Copy |
|---|---|
| Blocked, card title | Finish these first |
| Blocked, body | This module builds on the modules below. You can still read it, but it shows as Blocked until they are complete: every lesson read and confidence rated 3 or more. |
| Per prerequisite | {code} {title} · {n} of {total} lessons read · confidence {n} of 5 / confidence not rated |
| Button | Open anyway |
| After Open anyway | Opened before its prerequisites (compact card, list kept) |
| All met | Prerequisites complete |

### Lesson and module actions

| Control | Copy |
|---|---|
| Read toggle | Mark read / Mark unread |
| Toast on read | Lesson marked read. Module progress updated. |
| Bookmark toggle | Bookmark / Bookmarked |
| Confidence legend | How confident are you with this module? |
| Confidence hint | 1 means "I could not explain it yet"; 5 means "I could teach it". Rate again any time. |
| Confidence scale | 1 Lost, 2 Shaky, 3 Getting there, 4 Confident, 5 Could teach it |
| Confidence status | Not rated yet. / Last rated {n} of 5 on {5 October 2026}. |
| Toast on rating | Confidence set to {n} of 5. |
| Notes label and hint | Your notes on this module. Saved in this browser when you leave the box. |
| Toast on notes | Notes saved. |

### Empty and error states

| State | Copy |
|---|---|
| Storage blocked (every Learn page) | **Progress won't be saved in this browser.** Storage is blocked (private window or site data turned off). You can still read everything. [Dismiss] |
| A write fails | That didn't save. Storage may be full or blocked in this browser. |
| `/learn` filters match nothing | **No tracks match these filters.** Clear a filter to see more tracks. [Clear filters] |
| Before progress loads | Skeleton pill in place of the status badge; progress bars at 0 |
