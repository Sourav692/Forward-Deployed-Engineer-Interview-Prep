# T8.2 Mock Interviews and Scorecards: Consolidated Lessons

These six lessons are the site's teaching copy of module T8.2 "Mock interviews and scorecards". The first teaches how to run and score a mock once. Each of the other five is one practice mock that combines the short warm-up round and the full round for one scenario, with weak, average and strong versions and a scorecard. The site publishes them at `/interview/mock-interviews`.

## Sources

- `03_Practice_Worksheets_and_Keys/Mock_Interviews/Short_Practice_Mocks/` (five files, own material).
- `03_Practice_Worksheets_and_Keys/Mock_Interviews/Full_Mock_Interviews/` (five files and a README, own material).

The source files stay in the repository unchanged. The site no longer publishes the two folders as separate lessons; both old URLs redirect to lesson 1, which links to every scenario.

The five short mocks are word-for-word identical apart from the scenario name, and the full mocks share most of their transcript. Shared material is taught once in lesson 1; each scenario lesson keeps only what is specific to its case. Edit these files, not the generated copies under `site/content/learn/`, then run `npm run sync` from `site/`.
