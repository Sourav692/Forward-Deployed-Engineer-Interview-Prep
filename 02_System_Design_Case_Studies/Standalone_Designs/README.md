# Standalone Designs

One-off designs that are not part of the G01–G20 scenario packs. Each folder is one case, published on the site under the FDE Case Studies module.

Inside each case folder, every site tab has its own numbered subfolder named after the tab, such as `1_Interview_Casebook/04_Interview_Casebook.md` or `3_Tutorial/19_Tutorial.md`. Long documents continue in `_Part_N.md` files beside part 1. The Worksheet and Model Answer tabs of cases 19, 23, 25 and 26 are read from `03_Practice_Worksheets_and_Keys/System_Design_Worksheets/`, so they have no copy here. `STANDALONE` in `site/scripts/case-studies.mjs` lists every file.

| Folder | Case |
|---|---|
| `04_Recruiting_Platform` | AI-powered recruiting platform |
| `14_Travel_Agent_Worked_Example` | The 12-part framework worked through on a travel agent |
| `19_Air_Gapped_AI_System` | AI system for an air-gapped environment |
| `23_Reliable_Workflow_Orchestration` | Reliable workflow orchestration system |
| `25_Configurable_Platform_Customer_Workflows` | Configurable platform for customer-specific workflows |
| `26_Enterprise_Chatbot_Platform` | Enterprise chatbot platform |
| `60_Prioritize_AI_Use_Cases` | Prioritise AI use cases |
| `61_Scale_Prototype_To_Production` | Scale a prototype from 100 to 100,000 users |
| `62_Build_When_Customer_Data_Is_Poor` | Build when the customer's data is poor |
| `80_Self_Adapting_Agent` | Agent that adapts to new tasks |
| `98_Personal_Assistant_With_Memory` | Personal assistant that remembers you |
| `100_Production_LLM_Gateway` | Production LLM gateway |
| `Decomposition_Classics_67_68_69` | 911 dispatch, bank fraud, medication errors |

Cases 19, 23, 25 and 26 keep only their V2 tutorial here. Their worksheet, answer key and V1 tutorial are read from `03_Practice_Worksheets_and_Keys/System_Design_Worksheets/` and `Scenario_Tutorials_Long_Form/Version_1/` (declared in `site/scripts/case-studies.mjs`).
