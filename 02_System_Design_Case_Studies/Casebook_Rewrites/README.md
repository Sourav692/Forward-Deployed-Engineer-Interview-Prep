# Casebook teaching rewrites

This folder is the only source of the five-section casebooks shown at `/design/<slug>`. Edit them here, with the `casebook-content` skill in `.claude/skills/casebook-content/` (a copy for Codex is in `.agents/skills/casebook-content/`).

Each `<slug>/` folder holds:

| File | Role |
|---|---|
| `casebook.md`, `case.json` | Teaching content and metadata (coverage, aliases, rubric). Edit these. |
| `source.json`, `source-assets/` | Captured original page and its figures, hashed. Never edit. |
| `visual-review.json` | The reviewer's record of the screenshot and figure inspection. |
| `reader.html`, `snapshot.json` | Generated by `publish.py`. Never edit. |
| `live-check.json` | The latest production check. |

`rewrite-tracker.json` is the tracker record, and `TRACKER.md` is generated from it by `tracker.py`. `catalog.json` lists the 33 cases as captured.

From the repository root:

```sh
python3 .claude/skills/casebook-content/scripts/finish_case.py SLUG     # build and check into .casebook-build/SLUG/ (git-ignored)
python3 .claude/skills/casebook-content/scripts/publish.py --slug SLUG  # write reader.html and snapshot.json
cd site && npm run sync                                                  # copy into site/content/casebooks/ and site/public/casebook-assets/
```

Sync rejects a reader whose `casebook.md`, `case.json` or `reader.html` hash no longer matches `snapshot.json`, so rebuild and publish after every edit.
