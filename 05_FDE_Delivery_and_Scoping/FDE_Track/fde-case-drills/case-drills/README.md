# Short case drills: lesson sources

These files are the source of the module `case-drills` in the `fde-case-drills` track (End-to-end engagements). The site publishes them at `/learn/fde-case-drills/case-drills` once they are written and wired in `site/src/lib/curriculum.ts`.

Six short drills, two per lesson, each run as decompose, design, then follow-up questions in 20 minutes. Each drill links to its full casebook case or end-to-end simulation. The practice lessons sit in the `decomposition` interview round.

## Sources

Each lesson lists its primary sources (standards, vendor documentation, engineering books and papers) in its own References section. Customers, names and figures in the lessons are fictional and labelled as illustrations.

## Editing

Edit these files, not the generated copies under `site/content/learn/`, then run `npm run sync` from `site/`. File names are working titles until each lesson is written; the site slug is fixed once the lesson is published.
